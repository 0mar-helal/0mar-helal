## 👨‍💻 About Me

I'm **Omar Helal**, a Frontend Developer with **2+ years of professional experience** building modern websites and web applications.

I specialize in **React.js, Next.js, TypeScript, and Material UI**, with a strong focus on creating clean, scalable, responsive, and user-friendly interfaces.

I enjoy turning complex requirements and UI/UX designs into polished digital experiences while maintaining clean architecture, reusable components, performance, accessibility, and maintainable code.

### What I focus on:

- ⚛️ Building scalable applications with **React.js & Next.js**
- 🔷 Developing reliable, type-safe applications with **TypeScript**
- 🎨 Creating responsive and polished interfaces with **Material UI & Tailwind CSS**
- 🌍 Building multilingual applications with **i18n, RTL & LTR support**
- 🌙 Implementing professional **Dark & Light Mode** experiences
- ⚡ Improving **performance, SEO, accessibility, and Core Web Vitals**
- 🧩 Creating reusable components and maintainable frontend architectures
- 🔌 Integrating frontend applications with **REST APIs**
- 📱 Delivering responsive experiences across desktop, tablet, and mobile
- 🤝 Collaborating effectively with designers, backend developers, and product teams

I'm continuously improving my frontend engineering skills and exploring better ways to build fast, accessible, maintainable, and visually engaging web applications.
